# Workbook Go
A repo to generate customized worksheet for kids

可定制作业纸生成器

## 练字

### 填字格的格式

 - 可定制每行多少个字，这个可以决定格子的大小
 - 每个字都有若干格子，全部是虚线田字格的底子，按以下顺序：
   - 参考字，纯黑
   - 接下来的格子，每一个格子递增一个笔划，笔划顺序按照标准中文写法。这些笔划是灰色，方便用铅笔覆盖。一行放不下可以换行继续。
   - 若干格子用来练习。
 - 作为底子的田字格是灰色，虚线，就是普通练字本那种样子。

### 用户需求

 - 终端输入`workbook_go 一二三四五 -n 5 -o output/practice.pdf`
   - “一二三四五”这五个字都要分别学习。
   - 每行五个田字格。
   - 输出到output/practice.pdf，如果没有指定文件名，文件名自动为practice_<日期年月日>.pdf，如果有重复名字则自动添加数字后缀（在.pdf前）
 - 其它选项
   - -m/--mode 选项有1,2,3，这个选项决定了每个字配备什么样的格子
     - mode 1: default，每一个字都是参考字-笔划叠加-接下来的格子全都跟笔划叠加完毕的格子一模一样
     - mode 2: 参考字-笔划叠加-空格子
     - mode 3：无需笔划慢慢叠加，直接就是笔划全部都有的可以描字的格子
